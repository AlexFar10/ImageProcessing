Edges and sharpening

Derivative = difference between neighbours

  • An edge is where the values change fast. A derivative measures change.
  • First derivative: f(x+1) − f(x).
  • Second derivative: f(x+1) + f(x−1) − 2f(x).
  • Both are 0 on flat areas.

Sobel

  • Sobel: two kernels, one per direction. Both sum to 0, so flat areas give 0.
  • dx (horizontal derivative) = [-1 0 1; -2 0 2; -1 0 1]: finds vertical edges.
  • dy (vertical derivative) = [-1 -2 -1; 0 0 0; 1 2 1]: finds horizontal edges.
  • Edge strength: the gradient magnitude M = √(dx² + dy²).
  • Note: the lecture slide calls them gx / gy the other way round, because it takes x as the row direction. Here we use OpenCV's names.

Laplacian and sharpening

  • Laplacian = second derivative in both directions: 4 neighbours − 4 × centre, kernel [0 1 0; 1 -4 1; 0 1 0].
  • Alone it shows only the edges, on a dark background.
  • Sharpening: g = f + c · Laplacian, with c = −1 for this kernel.
  • Unsharp masking: blur, subtract (the mask), add back: g = f + k · mask. k = 1: unsharp masking, k > 1: highboost.

import cv2
import numpy as np
import matplotlib.pyplot as plt

gray = cv2.cvtColor(cv2.imread("landscape.png"), cv2.COLOR_BGR2GRAY)

gx8 = cv2.Sobel(gray, cv2.CV_8U, 1, 0)
gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0)
gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1)
print(np.count_nonzero(gx8), np.count_nonzero(gx > 0), np.count_nonzero(gx < 0))

mag = cv2.magnitude(gx, gy)
print(round(float(mag.max()), 1))
mag8 = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX).astype(np.uint8)
T, edges = cv2.threshold(mag8, 50, 255, cv2.THRESH_BINARY)

shown = [("gx8", gx8), ("|gx|", np.clip(np.abs(gx), 0, 255)), ("mag8", mag8), ("edges", edges)]
for i, (name, img) in enumerate(shown):
    plt.subplot(1, 4, i + 1)
    plt.imshow(img, cmap="gray", vmin=0, vmax=255)
    plt.title(name)
    plt.axis("off")
plt.show()

# 3. minus = np.clip(gray - lap, 0, 255).astype(np.uint8)     c = -1
#    plus = np.clip(gray + lap, 0, 255).astype(np.uint8)      c = +1
# 4. print(round(minus.mean(), 2), round(plus.mean(), 2)); show gray, lap, minus, plus


      
Question: which sign sharpens, and why?

      

        Show solution
        
import cv2
import numpy as np
import matplotlib.pyplot as plt

gray = cv2.cvtColor(cv2.imread("landscape.png"), cv2.COLOR_BGR2GRAY)

lap = cv2.Laplacian(gray, cv2.CV_32F)
print(lap.min(), lap.max())
minus = np.clip(gray - lap, 0, 255).astype(np.uint8)   # sharper: the centre is -4
plus = np.clip(gray + lap, 0, 255).astype(np.uint8)    # softer
print(round(minus.mean(), 2), round(plus.mean(), 2))

shown = [("gray", gray), ("|lap|", np.clip(np.abs(lap), 0, 255)), ("c = -1", minus), ("c = +1", plus)]
for i, (name, img) in enumerate(shown):
    plt.subplot(1, 4, i + 1)
    plt.imshow(img, cmap="gray", vmin=0, vmax=255)
    plt.title(name)
    plt.axis("off")
plt.show()

Question: how many multiplications per pixel does each version need for 31 × 31?

      

        Show solution
        
import time
import cv2
import numpy as np
import matplotlib.pyplot as plt

gray = cv2.cvtColor(cv2.imread("landscape.png"), cv2.COLOR_BGR2GRAY)

blur = cv2.GaussianBlur(gray, (31, 31), 5)
mask = gray.astype(np.float32) - blur
for i, k in enumerate((1, 4.5)):
    g = np.clip(gray + k * mask, 0, 255).astype(np.uint8)
    plt.subplot(1, 2, i + 1)
    plt.imshow(g, cmap="gray", vmin=0, vmax=255)
    plt.title(f"k = {k}")
    plt.axis("off")
plt.show()

k1 = cv2.getGaussianKernel(31, 5)
t0 = time.perf_counter()
sep = cv2.sepFilter2D(gray, -1, k1, k1)
t1 = time.perf_counter()
full = cv2.filter2D(gray, -1, k1 @ k1.T)
t2 = time.perf_counter()
print(f"separable {t1 - t0:.5f} s, 2D {t2 - t1:.5f} s")
print(np.abs(sep.astype(int) - full.astype(int)).max())   # 0 or 1: rounding only
# separable: 31 + 31 = 62 multiplications per pixel, 2D: 31 * 31 = 961


      

    

  


  
  

    

      
A kernel whose coefficients sum to 0, on a flat area, gives…

      

        
        
        
      

      
All neighbours are equal, so the sum is value × (sum of coefficients) = 0.

    

    

      
With 8-bit (CV_8U) output, negative Sobel responses become…

      

        
        
        
      

      
OpenCV saturates: everything below 0 is stored as 0, so edges going from bright to dark disappear.

    

    

      
Original + c · Laplacian (kernel with −4 in the centre, c = −1) gives…

      

        
        
        
      

      
The dark side of each edge gets darker and the bright side brighter.

k = 1 is unsharp masking; a bigger k boosts the details even more.
