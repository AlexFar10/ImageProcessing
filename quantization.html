Quantization and dithering

  • Quantization: keep fewer gray levels. k bits → 2k levels.
  • Lab formula: Δ = 256 / levels, q = floor(v / Δ) · Δ + Δ / 2.
  • Few levels → false contours: bands in smooth areas (sky), hidden in texture (grass).
  • Dithering: mix dots of the levels you have, the eye sees the missing grays.
  • Floyd–Steinberg: round a pixel, pass its error to the next ones:

def quantize(gray, levels):
    step = 256 / levels
    q = np.floor(gray.astype(np.float64) / step) * step + step / 2
    return np.clip(q, 0, 255).astype(np.uint8)

def floyd_steinberg(gray, levels=2):
    f = gray.astype(np.float64)
    step = 255 / (levels - 1)
    h, w = f.shape
    for y in range(h):
        for x in range(w):
            old = f[y, x]
            new = np.round(old / step) * step
            f[y, x] = new
            err = old - new
            if x + 1 < w: f[y, x + 1] += err * 7 / 16
            if y + 1 < h:
                if x > 0: f[y + 1, x - 1] += err * 3 / 16
                f[y + 1, x] += err * 5 / 16
                if x + 1 < w: f[y + 1, x + 1] += err * 1 / 16
    return np.clip(f, 0, 255).astype(np.uint8)
