The image as a grid of numbers

  • An image is a grid of pixels. Gray pixel: 1 number (0 black … 255 white). Color pixel: 3 numbers [B G R].
  • img[row, col]: row first, counted from the top-left corner (0, 0).
  • img.shape = (rows, columns, channels).
  • OpenCV drawing takes points as (x, y) = (col, row).
  • uint8 holds 0…255: NumPy 250 + 10 → 4 (wraps), cv2.add → 255 (saturates).
  • img[a:b, c:d] is a view: changing it changes img. Use .copy() for a separate image.
