Color and grayscale

  • A color is red, green and blue light, each 0…255 (RGB). Red + green = yellow, all three = white.
  • OpenCV stores B, G, R: img[:, :, 0] is blue, img[:, :, 2] is red.
  • Plain average (R + G + B) / 3 treats all colors the same.
  • Our eyes see green brightest, blue darkest, so gray uses a weighted average: 0.299 R + 0.587 G + 0.114 B (= cv2.cvtColor).

import cv2
import numpy as np

img = cv2.imread("landscape.png")
b, g, r = cv2.split(img.astype(np.float64))
ref = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

avg = np.round((b + g + r) / 3).astype(np.uint8)
weighted = 0.114 * b + 0.587 * g + 0.299 * r
weighted = np.clip(np.round(weighted), 0, 255).astype(np.uint8)

print(round(avg.mean(), 2), round(weighted.mean(), 2), round(ref.mean(), 2))
h, w = ref.shape
print(avg[h // 2, w // 2], weighted[h // 2, w // 2], ref[h // 2, w // 2])
diff = np.abs(weighted.astype(int) - ref.astype(int))
print(np.count_nonzero(diff), diff.max())
