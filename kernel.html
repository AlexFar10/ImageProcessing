Kernel and blur

The kernel

  • A filter slides a small matrix, the kernel, over the image.
  • At each pixel: multiply the neighbours by the coefficients and add. The sum is the new pixel.
  • The coefficients decide the effect. Sum 1: brightness stays. Sum 0: flat areas become 0.
  • A box kernel has equal coefficients: 1/9 for 3 × 3.

Correlation and convolution

  • Convolution = correlation with the kernel turned 180°.
  • Symmetric kernels (box, Gaussian, Laplacian): both give the same result.
  • cv2.filter2D computes correlation. On this site filters are correlation too: the kernel is not flipped.
  • It only matters for kernels that are not symmetric: Sobel changes sign.
  • Practical note (not in the lecture): template matching and the "convolution" layers of neural networks are correlation as well.

Borders

  • Pixels near the edge miss some neighbours, so the image is padded.
  • Zero padding adds a frame of zeros: the border gets darker.
  • Other choices: replicate the edge, or reflect it.
  • cv2.filter2D uses BORDER_REFLECT_101 by default. For zeros: borderType=cv2.BORDER_CONSTANT.

Box and Gaussian

  • Box: all weights equal. Gaussian: the centre counts most, weights fall with distance.
  • σ sets how wide the blur is. Kernel size ≈ 6σ + 1 (beyond 3σ the values are tiny).
  • For the same blur a Gaussian needs a larger kernel (lecture: box 71 × 71 vs Gaussian 151 × 151, σ = 25).
  • Both are separable: one pass along the rows, one along the columns.

        Show solution
        
import time
import cv2
import numpy as np

gray = cv2.cvtColor(cv2.imread("landscape.png"), cv2.COLOR_BGR2GRAY)
crop = gray[100:160, 100:180].astype(np.float32)
kernel = np.ones((3, 3), np.float32) / 9
h, w = crop.shape

t0 = time.perf_counter()
out = np.zeros_like(crop)
for r in range(1, h - 1):
    for c in range(1, w - 1):
        out[r, c] = (crop[r-1:r+2, c-1:c+2] * kernel).sum()
t1 = time.perf_counter()
ref = cv2.filter2D(crop, -1, kernel)
t2 = time.perf_counter()

print(round(float(out[30, 40]), 2))
print(np.abs(out - ref)[1:-1, 1:-1].max() < 1e-3)
print(f"loops {t1 - t0:.4f} s, filter2D {t2 - t1:.6f} s")

        Show solution
        
import cv2
import numpy as np
import matplotlib.pyplot as plt

gray = cv2.cvtColor(cv2.imread("landscape.png"), cv2.COLOR_BGR2GRAY)
kernels = {
    "identity": np.array([[0, 0, 0], [0, 1, 0], [0, 0, 0]], np.float32),  # no change
    "box":      np.ones((3, 3), np.float32) / 9,                          # blur
    "shift":    np.array([[0, 0, 0], [0, 0, 1], [0, 0, 0]], np.float32),  # moves 1 pixel left
    "edges":    np.array([[-1, 0, 1], [-1, 0, 1], [-1, 0, 1]], np.float32),  # vertical edges (dark to bright)
    "sharpen":  np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]], np.float32),  # sharper
}
out = {name: cv2.filter2D(gray, -1, k) for name, k in kernels.items()}
print(np.array_equal(out["shift"][:, :-1], gray[:, 1:]))

for i, name in enumerate(kernels):
    plt.subplot(1, 5, i + 1)
    plt.imshow(out[name], cmap="gray", vmin=0, vmax=255)
    plt.title(name)
    plt.axis("off")
plt.show()

Exercise 4 · Box vs Gaussian

      
Blur noisy.png with boxes and Gaussians of growing size and compare.

      
import cv2
import numpy as np
import matplotlib.pyplot as plt

noisy = cv2.imread("noisy.png", cv2.IMREAD_GRAYSCALE)

# 1. cv2.blur(noisy, (k, k)) for k = 3, 11, 21
# 2. cv2.GaussianBlur(noisy, (0, 0), s) for s = 1, 3, 7
# 3. show the noisy image and the six results in one row
# 4. diff = cv2.absdiff(box 11, the Gaussian that looks most like it); print(diff.mean())


      
Question: which one keeps the edges (house, fence) better at the same amount of smoothing?

      

        Show solution
        
import cv2
import numpy as np
import matplotlib.pyplot as plt

noisy = cv2.imread("noisy.png", cv2.IMREAD_GRAYSCALE)
results = [("noisy", noisy)]
for k in (3, 11, 21):
    results.append((f"box {k}", cv2.blur(noisy, (k, k))))
for s in (1, 3, 7):
    results.append((f"sigma {s}", cv2.GaussianBlur(noisy, (0, 0), s)))

for i, (name, img) in enumerate(results):
    plt.subplot(1, 7, i + 1)
    plt.imshow(img, cmap="gray", vmin=0, vmax=255)
    plt.title(name)
    plt.axis("off")
plt.show()

diff = cv2.absdiff(cv2.blur(noisy, (11, 11)), cv2.GaussianBlur(noisy, (0, 0), 3))
print(diff.mean())   # small: the two look alike
