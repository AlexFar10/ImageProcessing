Point operations

  • A point operation changes every pixel with the same function: a' = f(a). Neighbours and position do not matter.
  • Negative: 255 − a. Log: c · log(1 + a) brightens dark areas a lot.
  • Gamma: 255 · (a / 255)γ. γ < 1 brighter, γ > 1 darker.
  • Contrast stretching: map [a, b] to [0, 255]. With a = min and b = max it is automatic; cutting a few % at each end ignores outliers.
  • Equalization: new = round(H(a) / N · 255). The histogram spreads out, almost flat.
  • Merging levels cannot be undone; stretching leaves gaps in the histogram.

import cv2
import numpy as np

gray = cv2.cvtColor(cv2.imread("landscape.png"), cv2.COLOR_BGR2GRAY)
src = (gray * 0.4 + 30).astype(np.uint8)

lo, hi = int(src.min()), int(src.max())
out = (src.astype(np.float64) - lo) * 255 / (hi - lo)
stretched = np.clip(np.round(out), 0, 255).astype(np.uint8)
print(lo, hi, np.count_nonzero(np.bincount(stretched.ravel())))

hist = np.bincount(src.ravel(), minlength=256)
cdf = np.cumsum(hist)
lut = np.round(cdf / cdf[-1] * 255).astype(np.uint8)
mine = lut[src]
cv = cv2.equalizeHist(src)
print(round(mine.mean(), 2), round(cv.mean(), 2))
print(np.count_nonzero(mine != cv), np.abs(mine.astype(int) - cv).max())
